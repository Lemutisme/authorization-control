# Source and distribution scope

This is an anonymous research-review snapshot. Packaging does not assign a new open-source license to previously unlicensed authored code. Any existing notices within source files remain applicable.

AgentDojo, Progent and Pi are third-party projects with their own licenses and terms. Their full repositories, installed dependencies, model weights and provider credentials are not vendored here. The supplied study code uses or interfaces with those projects; source-proven benchmark examples and recorded simulated states appear in the experimental data.

The portable driver uses retained study analysis functions and the Python standard library. It makes no external API calls. A later public release may separately specify licensing and permanent archival hosting.
